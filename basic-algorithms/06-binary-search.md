# Binary Search

**Difficulty:** Easy

**Problem Link:** https://leetcode.com/problems/binary-search/

**Approach:**

Use two pointers, left and right, to find the middle element. Compare the middle element with the target and eliminate half of the search range each time.

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

**Notes:** Binary Search works only on a sorted array.
