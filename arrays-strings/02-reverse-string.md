# Reverse String

**Difficulty:** Easy

**Problem Link:** https://leetcode.com/problems/reverse-string/

**Approach:**

Use two pointers: one at the beginning and another at the end of the array. Swap the characters and move both pointers towards the center until they meet.

**Time Complexity:** O(n)

**Space Complexity:** O(1)

**Notes:** The string is reversed in place without using an extra array.
